Understanding Error Messages in RadHIL

Error messages in RadHIL are designed to provide clear information about issues that may occur during your use of the platform. This guide will help you understand common error messages, their meanings, and how to resolve them.

Common Error Messages

ERR_001: API Key Invalid

Meaning: The API key you're using is not recognized by our system.

Resolution: Verify your API key in the account settings. If the issue persists, generate a new API key.

ERR_002: Rate Limit Exceeded

Meaning: You've made too many requests in a short period of time.

Resolution: Wait for a few minutes before making new requests. If you consistently hit this limit, consider upgrading your plan.

ERR_003: Invalid Date Format

Meaning: The date you've entered is not in the correct format.

Resolution: Ensure all dates are in the format YYYY-MM-DD.

Debugging Error Messages

When encountering an error, you can use the following steps to debug:

  1. Check the error code and message carefully.
  2. Consult this knowledge base for common resolutions.
  3. Review your recent changes or inputs that might have caused the error.
  4. Check your account status and permissions.
  5. If the issue persists, contact our support team with the error details.

Error Logging

RadHIL automatically logs errors for debugging purposes. You can access these logs in your account settings. Here's an example of what an error log might look like:


2023-06-15 14:30:22 [ERR_001] API Key Invalid
Request URL: https://api.radhil.com/v1/properties
User ID: 12345
IP: 192.168.1.1

These logs can be invaluable when working with our support team to resolve persistent issues.

Custom Error Handling

If you're integrating RadHIL with your own systems, you may want to implement custom error handling. Here's a basic example in Python:


import requests

def radhil_api_call(endpoint, params):
    try:
        response = requests.get(f"https://api.radhil.com/v1/{endpoint}", params=params)
        response.raise_for_status()
        return response.json()
    except requests.exceptions.HTTPError as err:
        if err.response.status_code == 401:
            print("ERR_001: API Key Invalid. Please check your API key.")
        elif err.response.status_code == 429:
            print("ERR_002: Rate Limit Exceeded. Please wait before trying again.")
        else:
            print(f"An error occurred: {err}")
        return None

Contacting Support

If you're unable to resolve an error using this guide, don't hesitate to contact our support team. When reaching out, please provide:

  • The error code and full error message
  • Steps to reproduce the error
  • Any relevant logs or screenshots
  • Your account email address

Our team is dedicated to helping you resolve issues quickly and efficiently.

Remember, understanding error messages is key to efficiently managing your properties with RadHIL. If you encounter an error not covered in this guide, please let us know so we can continue to improve our documentation.
