User Roles and Permissions in RadHIL

RadHIL's user roles and permissions system is designed to provide flexible access control for your luxury vacation rental management team. Understanding and properly configuring these roles is crucial for maintaining security and efficiency in your operations.

Available User Roles

RadHIL offers the following predefined user roles:

Role Description
Owner Full access to all features and settings, including billing and account management
Administrator Full access to all features except billing and account deletion
Property Manager Access to property management features, guest communication, and reporting
Booking Agent Access to booking management and guest communication features
Maintenance Staff Access to maintenance schedules and task management
Accountant Access to financial reports and transaction history
Guest Services Access to guest communication and concierge features

Customizing User Permissions

While the predefined roles cover most use cases, RadHIL also allows for granular permission customization:

  1. Navigate to "Settings" > "User Management" in your RadHIL dashboard
  2. Select a user or create a new one
  3. Click on "Custom Permissions"
  4. Use the checkboxes to grant or revoke specific permissions
  5. Click "Save" to apply the changes

Best Practices for User Role Management

  • Follow the principle of least privilege: Give users only the permissions they need to perform their jobs
  • Regularly review and audit user roles and permissions
  • Use custom roles for unique organizational needs rather than over-permissioning standard roles
  • Implement a process for quickly revoking access when team members leave
  • Train your team on the importance of maintaining account security

Setting Up Two-Factor Authentication (2FA)

For enhanced security, RadHIL supports two-factor authentication for all user roles. To enable 2FA:

  1. Go to "Settings" > "Security" in your user profile
  2. Click "Enable Two-Factor Authentication"
  3. Choose your preferred 2FA method (SMS, authenticator app, or security key)
  4. Follow the on-screen instructions to complete the setup

We strongly recommend enabling 2FA for all users, especially those with administrative access.

Activity Logging and Auditing

RadHIL maintains detailed logs of user activities, which can be accessed by Owners and Administrators:

  1. Navigate to "Settings" > "Activity Logs"
  2. Use filters to search for specific actions, users, or date ranges
  3. Export logs for external auditing if required

Regular review of these logs can help identify unusual activities and maintain the security of your RadHIL account.
