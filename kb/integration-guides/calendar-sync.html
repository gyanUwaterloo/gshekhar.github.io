Calendar Sync Integration Guide

Seamless calendar synchronization is crucial for managing luxury properties efficiently. RadHIL's Calendar Sync integration ensures that your bookings, maintenance schedules, and personal calendars are always up-to-date across all platforms. This guide will walk you through the process of setting up and optimizing calendar sync for your RadHIL account.

Supported Calendar Platforms

  • Google Calendar
  • Apple iCloud Calendar
  • Microsoft Outlook Calendar
  • Airbnb Calendar
  • Booking.com Calendar
  • VRBO Calendar

General Integration Steps

  1. Log in to your RadHIL dashboard
  2. Navigate to "Integrations" in the main menu
  3. Select "Calendar Sync" from the integration categories
  4. Choose the calendar platforms you want to sync with RadHIL
  5. Click "Connect" for each platform and follow the authentication process
  6. Configure sync settings for each connected calendar
  7. Set up two-way sync or one-way sync as needed
  8. Test the integration by adding a test event
  9. Activate the live sync

Google Calendar Integration

Google Calendar is widely used and offers robust synchronization capabilities. Here's how to set it up with RadHIL:

  1. In the RadHIL dashboard, select Google Calendar from the calendar platforms list
  2. Click "Connect to Google Calendar"
  3. You'll be redirected to Google's authorization page. Log in and grant access to RadHIL
  4. Back in RadHIL, click "Configure Sync Settings"
  5. Choose which RadHIL calendars to sync with Google:
    • Property Bookings
    • Maintenance Schedules
    • Cleaning Schedules
    • Staff Schedules
  6. Set up sync direction (two-way or one-way)
  7. Configure event color coding for different types of events
  8. Set up privacy settings for synced events
  9. Save your configuration
// Example of RadHIL to Google Calendar sync configuration { "propertyBookings": { "syncEnabled": true, "syncDirection": "twoWay", "colorCode": "#4285F4", "privacy": "public" }, "maintenanceSchedules": { "syncEnabled": true, "syncDirection": "oneWay", "colorCode": "#FBBC05", "privacy": "private" } }

Airbnb Calendar Sync

Syncing with Airbnb's calendar is crucial for avoiding double bookings. Here's how to set it up:

  1. Select Airbnb from the calendar platforms list in RadHIL
  2. Click "Connect to Airbnb Calendar"
  3. You'll be prompted to enter your Airbnb iCal URL for each property
  4. In Airbnb, go to your listing, find the calendar export option, and copy the iCal URL
  5. Paste the URL into RadHIL for each corresponding property
  6. Set the sync frequency (e.g., every 15 minutes, hourly, daily)
  7. Configure how RadHIL should handle conflicting bookings
  8. Save your configuration

Note: Airbnb calendar sync is typically one-way (Airbnb to RadHIL) to prevent potential overbooking issues.

Advanced Calendar Sync Features

RadHIL's calendar sync offers advanced features for power users:

  • Multi-property Overview: Sync all your properties into a single, color-coded calendar view
  • Availability Blocks: Automatically block off maintenance periods across all synced calendars
  • Smart Conflict Resolution: AI-powered suggestions for resolving booking conflicts
  • Custom Event Types: Create and sync custom event types (e.g., photoshoots, inspections)
  • Calendar Analytics: Get insights on booking patterns and occupancy rates

Best Practices for Calendar Sync

  • Regularly verify that all calendars are syncing correctly
  • Use unique, descriptive names for each property to avoid confusion
  • Set up notifications for sync errors or conflicts
  • Implement a buffer period between bookings to account for cleaning and maintenance
  • Train your team on the importance of keeping calendars updated
  • Periodically review and update sync settings as your business grows

Troubleshooting Common Sync Issues

If you encounter problems with your calendar sync:

  1. Check your internet connection and ensure all platforms are accessible
  2. Verify that your authentication tokens are still valid for each platform
  3. Review sync logs in RadHIL for any error messages
  4. Try disconnecting and reconnecting the problematic calendar
  5. Ensure that the time zones are correctly
