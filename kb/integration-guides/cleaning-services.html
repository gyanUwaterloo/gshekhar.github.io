Cleaning Services Integration Guide

Integrating RadHIL with cleaning services ensures that your luxury properties are always pristine and ready for guests. This guide will walk you through the process of connecting RadHIL with various cleaning service platforms to automate and optimize your property maintenance.

Supported Cleaning Service Platforms

  • TurnoverBnB
  • Properly
  • Breezeway
  • VRScheduler
  • ResortCleaning

General Integration Steps

  1. Log in to your RadHIL dashboard
  2. Navigate to "Integrations" in the main menu
  3. Select "Cleaning Services" from the integration categories
  4. Choose your preferred cleaning service platform
  5. Click "Connect" and follow the authentication process
  6. Configure cleaning schedules and property details
  7. Set up automation rules for cleaning tasks
  8. Test the integration
  9. Activate the live integration

TurnoverBnB Integration

TurnoverBnB is a popular platform for managing cleaning services. Here's how to set it up with RadHIL:

  1. In the RadHIL dashboard, select TurnoverBnB from the cleaning services list
  2. Click "Connect to TurnoverBnB"
  3. You'll be redirected to TurnoverBnB's authorization page. Log in and grant access to RadHIL
  4. Back in RadHIL, click "Configure Integration"
  5. Map your properties in RadHIL to TurnoverBnB:
    • Property Name
    • Address
    • Cleaning Instructions
    • Access Information (if applicable)
  6. Set up cleaning schedule rules:
    • Time between guest checkout and next check-in
    • Preferred cleaning times
    • Special cleaning requirements (e.g., deep clean every 5th booking)
  7. Configure notifications for cleaning status updates
  8. Save your configuration

Properly Integration

Properly offers visual checklists for cleaners. Here's how to integrate it with RadHIL:

  1. Select Properly from the cleaning services list in RadHIL
  2. Click "Connect to Properly"
  3. Authorize the connection on the Properly website
  4. In RadHIL, click "Configure Integration"
  5. Import or create visual checklists for each property
  6. Set up automatic cleaning task creation based on bookings
  7. Configure quality control settings and inspection schedules
  8. Save your configuration

Note: Ensure that your cleaning staff has access to the Properly app to receive tasks and submit completion reports.

Automation Features

With RadHIL's cleaning service integration, you can automate the following:

  • Scheduling cleanings based on guest check-out and check-in times
  • Assigning cleaners to specific properties or rotations
  • Sending cleaning instructions and access information to cleaners
  • Tracking cleaning progress and completion status
  • Generating reports on cleaning efficiency and quality
  • Automated billing and invoicing for cleaning services

Best Practices for Cleaning Integration

  • Create detailed property profiles with specific cleaning requirements
  • Establish clear communication channels between property managers, cleaners, and guests
  • Regularly update cleaning checklists to maintain high standards
  • Implement a quality control process with random inspections
  • Use guest feedback to continuously improve cleaning processes
  • Train cleaning staff on using the integrated system effectively

Handling Special Cleaning Requests

RadHIL's integration allows for special cleaning requests to be seamlessly communicated:

  1. Set up custom fields in guest booking forms for special requests
  2. Configure automation rules to flag bookings with special requests
  3. Ensure these requests are automatically added to cleaning tasks
  4. Implement a review process for complex or unusual requests

Troubleshooting Common Issues

If you encounter problems with your cleaning service integration:

  1. Verify that all properties are correctly mapped between RadHIL and the cleaning platform
  2. Check that cleaning schedules align with your booking calendar
  3. Ensure cleaners have the necessary access to properties and the cleaning platform's app
